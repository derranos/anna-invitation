# Приглашение для Анны

Минимальный сайт-визитка без сборки (сборка — отдельная подготовка проекта). Ответы отправляются в опубликованную Google Форму и сохраняются в связанную Google Таблицу.

## Запуск

1. Загрузите содержимое этой папки на GitHub Pages или другой статический хостинг (хостинг — сервис публикации файлов сайта).
2. Убедитесь, что форма опубликована и принимает ответы без обязательного входа в Google.
3. Откройте сайт. Python-сервер для сохранения ответов больше не нужен.

В `app.js` уже указаны адрес формы и поля:

- `Мероприятие` — `entry.1647409354`;
- `Дата` — `entry.302324213`;
- `Время` — `entry.211935560`.

Для локальной проверки из этой папки можно запустить:

```bash
python server.py
```

Затем откройте `http://localhost:8080`. Сервер нужен только для просмотра сайта локально; отправка всё равно идёт в Google Форму.
