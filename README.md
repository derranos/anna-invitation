# Приглашение для Анны

Минимальный сайт-визитка без сборки (сборка — отдельная подготовка проекта) и внешних зависимостей. Основа сервера — Python со стандартной библиотекой.

## Запуск

1. Загрузите содержимое этой папки на сервер с Python.
2. В папке проекта запустите `python server.py`.
3. Откройте `http://адрес-сервера:8080`. Не запускайте `index.html` двойным щелчком: сохранение ответа работает через Python-сервер.

Ответы добавляются построчно в `answer.txt` в формате JSON (структурированный текстовый формат).

Для локальной проверки из этой папки:

```bash
python server.py
```

Затем откройте `http://localhost:8080`.
